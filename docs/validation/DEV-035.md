## 结果语义

- 本地 TOTP 验证由 TeamLedger 和标准离线 Authenticator 独立完成；运行时不依赖 OIDC、外部 MFA、KMS 或二维码服务。
- 密码单独只能得到十分钟受限 session；只有完成 TOTP 后才能签发 `AMR=["pwd","otp"]` 的业务 session。
- 恢复码不能直接进入业务页面，只能与当前密码一起原子消费并登记新 factor；旧码、旧 factor、旧 session 和旧 generation 不可复活。
- 既有部署必须按 README 执行 v13→v14 migration 和 16→18 key domain 显式升级/数据库确认；失败时 API 保持不可 ready，不清库、不自动生成替代 root。
