# DEV-046 验证摘要

- 日期：2026-10-16
- 范围：人员XLSX语义类型兼容、可编辑预览与服务端重验、org级学历目录、schema v18迁移。

## 已验证行为

- Staff Code：Text保留原值；Excel Number仅在无符号十进制整数时按原始lexical值转文本并返回`numeric_staff_code_coerced`。空值只报一次`staff_code_required`；decimal/scientific/sign数字不舍入、不猜前导零。
- 日期：既有确定文本格式继续规范为ISO；Excel整数serial按工作簿实际1900/1904系统转换；OOXML date/零时刻datetime可读。1900 serial 60、负数、fraction、scientific及非零时间阻断并定位原cell。
- 其他字段：numeric lexical value保留并警告；Boolean/Error及不适用列的Date保留raw并要求编辑。Location大小写和唯一目录code/label可规范；歧义不猜测。
- 页面：18字段均可编辑；编辑后原校验失效，只有`POST .../import-review`完整重验后才能创建。errors/warnings分区显示；文件保留供重新校验。
- 学历：schema v18将学历目录改为`(org_id,code,rank)`；v17既有三档及education记录迁移保留，新org初始化Master/Bachelor/Diploma。未知学历不由preview自动写库；明确rank追加后重新review。
- 容量：100行可编辑review允许至5MiB，覆盖100个合法长profile使JSON超过普通256KiB的情形；普通JSON body限制不变。
- 备份：backup manifest/restore的受支持schema同步更新为v18。
