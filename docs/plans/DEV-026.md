# PLAN · DEV-026 · 人员资料布局与无闪烁导航

- 日期：2026-10-15
- 状态：完成
- 目标：重构人员资料录入的信息结构，并让应用内tab切换保持已核对身份壳层稳定；不改变字段、校验、权限、API及敏感状态销毁边界。

## 问题与决定

1. **人员资料布局**：旧表单把`label`和control作为同一自动grid的独立子项，造成标签、输入框、textarea和日期跨列错位。改为“页面说明→查询条件→基本资料→工作联系方式→生命周期/更正依据→固定提交区”；每个字段由单一label包裹control。
2. **tab闪屏根因**：应用内`pushState`后人工派发`popstate`，`IdentityGate.routeChanged()`调用破坏式`checkSession()`；其先切换到`checking`、增加protected generation并卸载整个业务壳层，成功后再挂载，因此每次tab切换均短暂显示会话核对页。
3. **导航方案**：真实路由变化仍重新向服务端核对会话，但已有会话时采用非破坏式后台核对；相同主体/组织/auth epoch时保持壳层，只切换业务页。401、身份上下文变化、敏感期限失效或核对失败仍立即销毁保护内容。显式“重新核对会话”、focus/pageshow和pagehide安全边界保持破坏式语义。
4. **独立部署**：不增加前端依赖、路由服务或外部视觉资源。

## 验收
