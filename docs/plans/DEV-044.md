# PLAN · DEV-044 · 明确授权筛选界面重构

- 日期：2026-10-16
- 状态：T1–T4全部完成
- 问题：P-SEC-01筛选表单把`label`和控件作为独立grid item排列，宽屏下视觉顺序与字段归属错位；11个条件无主次地同时展开，技术型成对条件挤占主要操作空间。

## 设计决定

1. 每个字段使用一个完整的`label + 名称/说明 + control`单元，视觉和无障碍归属一致。
2. 常用条件固定显示：主体ID、状态、能力、类别、目的。
3. 作用范围、授权ID和具体对象归入默认收起的“高级筛选”；scope类型/ID及对象类型/ID在同一行成对显示。
4. 每页条数与“应用筛选”形成独立底部操作区，不再混入字段矩阵。
5. 桌面使用三列信息层级，中等宽度两列，手机单列；不改变现有查询参数、权限、安全校验或分页语义。

## 验收

- 初次打开时只显示五个常用条件和底部操作区。
- “高级筛选”展开后显示完整scope、grant及object条件；成对字段在桌面相邻、移动端按类型后ID顺序纵向排列。
- 原有状态筛选、typed object筛选、cursor丢弃和limit校验行为不变。
- 页面不出现横向溢出、标签悬空、输入框与相邻标签误配或按钮插入字段中间。
