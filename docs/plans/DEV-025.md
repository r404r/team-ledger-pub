# PLAN · DEV-025 · 统一产品UI设计与样式实装

- 日期：2026-10-15
- 状态：执行中
- 目标：在不改变业务、安全、授权和数据语义的前提下，为TeamLedger的身份壳层及全部9个稳定业务页面建立一致、可访问、响应式的产品视觉系统，并验证Docker production build的真实浏览器呈现。

## 设计决定

1. **气质**：企业级HR/财务产品，安静、可信、信息密度适中；使用深墨蓝＋青绿色强调、暖灰背景和少量状态色，不模仿消费级营销页。
2. **无外部前端依赖**：不引入CSS框架、图标包、远程字体、CDN、分析SDK或运行时主题服务；系统字体栈确保独立部署。
3. **统一但不掩盖语义**：全局tokens控制颜色、排版、间距、圆角、阴影、focus和状态；页面仍保留原生语义元素、ARIA、权限提示、明确确认和安全错误。
4. **密集业务可读性**：主壳层、sticky导航、卡片层级、响应式form grid、横向可滚动table、code/pre和长ID换行；不隐藏原字段或简化安全文案。
5. **可访问性**：键盘focus清晰；文本/控件对比度以WCAG AA为目标；支持`prefers-reduced-motion`；移动端不横向撑破viewport；触控目标最小约40px。
6. **边界**：本task不改API、路由、权限、状态机、敏感数据生命周期、文案契约或第三方集成；不增加主题切换和品牌配置后台。

## 实装范围

- 新增`web/src/styles.css`作为唯一全局视觉基础，并由`main.ts`加载。
- 重构`App.vue`为品牌栏＋当前导航状态＋响应式主导航。
- 重构`IdentityGate.vue`的认证态会话栏和未认证登录卡，但保持所有条件、事件、表单字段、清空语义与测试选择器。
- 通过全局语义层统一Profile、Grant、Audit、Organization、Interview、Compensation、Compensation Batch、Bonus、Followup页面；仅在确有专属布局时保留组件scoped规则。
- Docker/Vite继续输出hash CSS asset，由现有Go静态服务同源交付。
