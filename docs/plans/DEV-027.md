# PLAN · DEV-027 · 紧凑会话与安全面板

- 日期：2026-10-15
- 状态：执行中
- 目标：把认证态顶部会话区域默认折叠为单行摘要，按需展开会话/MFA/密码操作，减少业务页面上方空间占用；不改变会话核对、MFA、注销、密码修改和fail-closed语义。

## 设计决定

1. 认证成功后默认只显示状态点、“会话已核对”、MFA摘要和“会话与安全”展开提示。
2. 使用原生`details/summary`提供键盘与assistive technology可操作的披露控件；完整说明、重新核对、注销、MFA和账号密码操作位于展开区。
3. 未认证、checking、expired、changed、unavailable及操作中状态继续使用完整身份页，不折叠安全错误或恢复操作。
4. 应用内tab切换保留用户当前展开状态；会话被销毁后面板实例随protected context销毁。
5. 不增加前端依赖、外部资源或浏览器持久化。
